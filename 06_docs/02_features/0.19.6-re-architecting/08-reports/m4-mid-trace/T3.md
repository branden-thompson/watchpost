# T3: DATA PULL on the UP NEXT card drops the date when the pull was today

`modes/tty/broadcaster_manifest.go:cardPulledShort` as "the card's DATA PULL stamp" and says it chooses a
date itself. I confirmed it with `docs/where-things-happen.md:75` and `docs/extending.md` Walkthrough 8,
step 1 (`readBody` in `modes/tty/broadcaster_slots.go`).

## Sites

1. **`modes/tty/broadcaster_manifest.go:127`, `cardPulledShort`**: when `now != nil` and `c.BuiltAt` falls
   on the same calendar date as `now()`, return only `o.Clock.TimeSec(c.BuiltAt) + "  " + <age>`. Otherwise
   keep `c.BuiltAt.Format("01/02/06  ")` in front, as today. Compare dates the way `spokenWhen` does
   (`y, m, d := …Date()`), in one zone; see "Where I stopped". When `now == nil` there is no "today", so
   keep the date. `readBody` always passes `b.clock` (a method value, never nil;
   `go doc -u -src ./modes/tty Broadcaster.clock`), so that branch is never taken from the card.
2. **The same function's doc comment** (`:115-126`): it gives the form as "`mm/dd/yy  23:59:59 (10 MIN AGO)`".
   Add the today form. The comment is the record of the form, and a stale one misleads the next reader.
3. **`modes/tty/broadcaster_manifest.go:91`, `cardPulled`** (the window's DATA PULLED line): **no change**, as
   the task says.
4. **`modes/tty/broadcaster_slots.go:154`, `readBody`**: **no change**. The `"DATA PULL: "` label is fixed.
   The row only gets shorter, and the card's height (`bcReadCardRows`) does not move.
5. **`CHANGELOG.md`, `[Unreleased]`**: one entry. Route: `docs/extending.md:250` (Walkthrough 8 step 7) and `:32`.

## Where I stopped

- **Which day is "today"?** `BuiltAt` is formatted in whatever zone it carries, and `now()` in its own.
  Should today be judged in the operator machine's local zone, the zone `BuiltAt` carries, or the
  transmitter's `tz` (`[broadcaster.transmitter]`)? `spokenWhen` uses `.Local()` on both, which is the
  obvious precedent, but I would ask.
- **Is the shortened stamp a Composer concern?** Walkthrough 8 (`docs/extending.md:253-255`) says it is
  unruled whether a line is the console's drawing or what the Card Composer says. This line is plainly the
  console's (`modes/tty`, from `Card.BuiltAt`), so I did not ask. I am noting the rule exists.
