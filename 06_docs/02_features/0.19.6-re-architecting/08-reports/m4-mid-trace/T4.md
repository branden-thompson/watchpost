## Where I stopped

- **"Yesterday" in whose day?** `spokenWhen` uses the machine's local zone, as today's "at" does. For a
  station whose transmitter is in another zone, this may not be the listener's day. I kept the precedent,
  but I would ask.
- **Should the words live in a script?** Walkthrough 7 says re-wording is normally a `.txt` edit that a user
  can override. "at", "on" and now "yesterday" are Go literals, so a user cannot re-word them. Is that
  deliberate? I would ask before moving any of them.
