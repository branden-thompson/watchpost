# T2: the UV legend row's head, `UV │` to `UV INDEX │`

Route used: `docs/extending.md` Walkthrough 5, step 1 (`docs/extending.md:154`). It names
`modes/tty/map_temp.go` as the file that holds the layer keys, `UVLayer` among them. The file's own
header covers Forecast mode. Inside it, `tempLegendRow` is the row "under the map in Forecast mode".
`docs/where-things-happen.md:28` ("feels-like, wind, UV and rain ride the same build", `app/maptemp.go`)

## Sites

1. **`modes/tty/map_temp.go:805`, `tempLegendRow`**: change the head argument of
   `d.presetRow("uv", "UV │ ", "LOW ", " EXTREME", width)` to `"UV INDEX │ "`.
   **Caveat on "nothing else changes":** `presetRow` (same file, about line 840) computes
   `room := width - render.Width(head+colder+warmer)`. Six more cells of head make each class's swatch
   narrower, so `each = room/len(classes)` drops and the class labels are cut sooner. At a narrow window,
   where `room < len(classes)*2`, the whole row now disappears (it returns "") at a width where it used to
   show. Keeping the swatches exactly as they are would need the room computed without the head, which
   would widen the row. That is a choice to ask about.
2. **`CHANGELOG.md`, `[Unreleased]`**: one entry. Route: `docs/extending.md:32`.

No `app/`, `platform/` or script change is needed. The words are a literal in `modes/tty`. I did not
find any other copy of "UV │".
