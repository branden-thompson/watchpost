0.16.0 — BROADCASTER RUNNING ORDER, v2 (HUM LEAD, 2026-09-11)

SUPERSEDES v1 BELOW THE STATION SECTION.  Two changes of substance:

  1. THE PRIORITY AND MAIN TRACKS ARE SPLIT.  No occlusion: the priority track is
     its own column beside the running order, not an overlay on top of it.
  2. A CARD IS A MANIFEST, NOT A TRANSCRIPT.  "The full script on the top level
     card doesn't make sense when I can drill down to read the whole thing …
     What DOES MAKE SENSE for the operator is to get a SUMMARY of what the
     report contains *before* it goes on air."

The right-hand inner wall is GONE.  Only the vertical scroll on positions 2-9.
