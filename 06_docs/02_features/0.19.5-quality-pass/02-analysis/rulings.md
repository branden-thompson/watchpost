# 0.19.5 — rulings

Recorded verbatim. A ruling's disposition says what it binds; a correction to a ruling is a new row,
never an edit of an old one. Rulings of 0.19.0 to 0.19.3 are cited as "0.19.0 D-n"
(`../../propagation-overlays/02-analysis/rulings.md`); of the 0.9.5 pass as "0.9.5"
(`../../watchpost-performance-quality-pass/`).

The pass, as the HUM LEAD set it (2026-11-05): "our regularly scheduled *.5 release, which is a
comprehensive quality / performance pass of the codebase. We're looking to: Ensure all existing
functionaliy is maintained (NO REGRESSIONS); We looks for performance improvements where possible
(without re-architecting charm/bubbletea); Look for places to *appropriately* consolidate functions
reduce/remove DRY violations; Ensure all documentation, artifacts, and code comments are up to date;
Esure code is approachable and understandable for Junior-level human maintainers".
